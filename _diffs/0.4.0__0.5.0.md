# CLI snapshot diff: 0.4.0 -> 0.5.0

## root-help

### Removed

```diff
-  -v, --verbosity...     Sets the level of verbosity: 0 = none, 1 = warning & error, 2 = info, 3 = debug, 4 = trace
```

### Added

```diff
+  -v, --verbosity...     Sets the level of logging verbosity: -v = warning & error, -vv = info, -vvv = debug, -vvvv = trace
```

## compile-help

### Removed

```diff
-  [OUTPUT]  Path to output PDF file
-      --open [<OPEN>]              Opens the output file after compilation using the default PDF viewer
-      --flamegraph [<OUTPUT_SVG>]  Produces a flamegraph of the compilation process and saves it to the given file or to `flamegraph.svg` in the current working directory
-  -h, --help                       Print help
```

### Added

```diff
+  [OUTPUT]  Path to output PDF file or PNG file(s)
+      --open [<OPEN>]
+          Opens the output file after compilation using the default PDF viewer
+      --ppi <PPI>
+          The PPI to use if exported as PNG
+      --diagnostic-format <DIAGNOSTIC_FORMAT>
+          In which format to emit diagnostics [default: human] [possible values: human, short]
+      --flamegraph [<OUTPUT_SVG>]
+          Produces a flamegraph of the compilation process
+  -h, --help
+          Print help
```
