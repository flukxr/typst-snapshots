Compiles the input file into a PDF file

Usage: typst.exe compile [OPTIONS] <INPUT> [OUTPUT]

Arguments:
  <INPUT>   Path to input Typst file
  [OUTPUT]  Path to output PDF file or PNG file(s)

Options:
      --open [<OPEN>]
          Opens the output file after compilation using the default PDF viewer
      --ppi <PPI>
          The PPI to use if exported as PNG
      --diagnostic-format <DIAGNOSTIC_FORMAT>
          In which format to emit diagnostics [default: human] [possible values: human, short]
      --flamegraph [<OUTPUT_SVG>]
          Produces a flamegraph of the compilation process
  -h, --help
          Print help
